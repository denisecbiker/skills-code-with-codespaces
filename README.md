## 🔍 Tech Stack Detection Tool

**New!** Want to know if your project uses Python, .NET, or React?

Run the tech stack detection tool:

```bash
python detect-tech-stack.py
```

This tool will analyze your repository and tell you:
- ✅ Whether your project uses Python
- ✅ Whether your project uses .NET (and which version)
- ✅ Whether your project uses React
- ℹ️ How these technologies might be integrated

For more details, see [TECH_STACK_DETECTION.md](TECH_STACK_DETECTION.md).
